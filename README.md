# Exact second-order cone tightening for stochastic tube MPC under multiplicative uncertainty

Code and numerical results for the manuscript *"Exact second-order cone tightening for stochastic tube model predictive
control under multiplicative uncertainty"* (M. Z. Asyari and S. Y. Shin, submitted to *Systems & Control Letters*).

For a fixed tube gain, the variance of the tube error along a constraint direction is a constant plus convex quadratic
forms of the nominal plan with offline kernels, so each Cantelli-tightened chance constraint is exactly a second-order
cone (SOC) constraint. The package implements this SOC formulation, the receding-horizon scheme with trace-weighted
terminal ingredients (Algorithm 1 of the paper), its dual-mode variant, and the fixed-gain LMI formulation of
Farina and Scattolini (Automatica 70, 2016) used as the baseline.

## Installation
Python 3.10 was used. Create a virtual environment and install the exact versions used for the paper:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
Run all commands from the repository root. Inside the virtual environment, `python` and `python3` are the same
interpreter; outside it, use `python3` (some systems have no `python` command).

Closed-loop runs use matched noise realisations (`numpy.random.default_rng(7000 + 1000*ix + r)` for the `ix`-th
initial state and run `r`), so rows of Table 1 are comparable run by run. All results are deterministic given the
code and package versions; solve times depend on the hardware (AMD Ryzen 7 5800H for the paper).

## Numerical settings
Clarabel with default settings through CVXPY (objective scaled by 1e-3); on numerical failure, SCS with `eps=1e-7`
and at most 20000 iterations. Every returned plan is checked a posteriori against the exact Cantelli constraints
(and terminal constraints) and accepted if the largest residual is at most 1e-6; otherwise the problem is reported as
unresolved, or as infeasible if the solver certifies infeasibility. Kernel factors drop eigenvalues below 1e-12
relative. Terminal ingredients: `cxsmpc/terminal.py` with a 2 % margin and the (lambda, H0) grid listed in
`scripts/exp023_terminal_params.py`; the design does not depend on the horizon N.
